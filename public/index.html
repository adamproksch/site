Features

Git deploys

Every push builds and restarts your bot. If the build fails the old version keeps running.

Web console

See logs and run commands from the panel, no SSH needed.

Auto restart

If your bot crashes it restarts and sends the last 20 log lines to a channel you pick.

Backups

Your files and databases get backed up every day.

6 regions

US East, US West, EU West, EU Central, Singapore and Sydney.

Own container

Each bot runs in its own container with set CPU and memory.

How it works

  1. Connect your repo - link GitHub or upload a zip. We figure out the language and start command.
  2. Add your token - paste your bot token and any env variables.
  3. Deploy - watch it build in the console and your bot comes online.
